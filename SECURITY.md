# Security

**This is a demonstration repository.** The service here is a sample application carrying
deliberately seeded defects, with no authentication and a trust-auth database. Run it locally only.
Do not deploy it, expose it to a network, or point it at data you care about.

To report a vulnerability in the Karate engine or in the material under `karate/`, use the Karate
Labs [contact form](https://www.karatelabs.io/contact-us) rather than opening a public issue, and
allow time for a fix before disclosing.

Defects in the sample application itself are the point of this repository; report those upstream at
[github.com/mourjo/quick-meetings](https://github.com/mourjo/quick-meetings) if they are not one of
the five seeded here.
